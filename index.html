Mengenal Lebih Dekat

Halo! Nama saya Imelda Nurcahyani. Saya merupakan siswi aktif di SMKN 1 Kawali, Kabupaten Ciamis, Jawa Barat. Saya menempuh pendidikan kejuruan pada bidang Pengembangan Perangkat Lunak dan Gim (PPLG / RPL).

Melalui pembelajaran kejuruan di SMKN 1 Kawali, saya terbiasa belajar praktik menyusun halaman web dari dasar, seperti membuat website Company Profile, merancang aplikasi Kasir (Point of Sale) untuk UMKM/koperasi sekolah, dan membangun antarmuka pengelolaan Data Siswa.

Di samping aktivitas di kelas dan lab komputer, saya aktif menyalurkan hobi bermain bola voli di lapangan olahraga SMKN 1 Kawali. Olahraga ini mengajarkan arti kerja sama tim, kecepatan respon, dan sportivitas tinggi.
